# Public source release record

**Repository:** [cschultz/analog-tickets](https://github.com/cschultz/analog-tickets)  
**Steward:** Launch Pad Foundation  
**License:** Apache-2.0  
**Release mode:** public source repository; no live demo or marketing launch

## Authorization

Chris Schultz approved publication of a new public `analog-tickets` repository from the sanitized source baseline on 2026-08-25.

This authorization does **not** publish the Lovable project, the Cosmico preview, production Cosmi, a live backend, or any marketing destination.

## Included

- Generic Analog Tickets application source, tests, and documentation
- Apache-2.0 license and contribution/security guidance
- Placeholder configuration and backend contract documentation
- Placeholder asset pointers documented in `docs/ASSET_RELEASE_GATE.md`

## Excluded

- Uncleared event photography, attendee or performer imagery, and production-era media
- Identifiable-minor imagery and explicitly excluded Joiner imagery
- Customer or sales data
- Credentials, secrets, live backend configuration, integrations, and database state
- Production Cosmi deployment, domains, and history

The media inventory is retained as documentation only. Exclusion from the public package is not a rights clearance.

## Deferred before a live demo or marketing release

- Fresh-backend schema/RLS deployment and end-to-end validation
- Stripe/webhook/email integration setup and security validation
- Final photography, font, logo, and copy clearance
- Lovable visibility, remix-template publication, custom domains, and Trust Center settings
- Public demo-site launch or traffic promotion

## Remix expectation

A remixer supplies their own backend, secrets, integrations, event configuration, and media. The application should run in site-only mode without a live payment backend; ticketing and integrated modes require a separately designed and reviewed backend.
