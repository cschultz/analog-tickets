# Asset release gate

This repository intentionally ships without photographic binaries at this stage.

## Approved temporary placeholders

- `film-camera-01.jpg` — generic hero placeholder; credit `@bmaphoto`
- `film-camera-02.jpg` — generic gallery placeholder; credit `@bmaphoto`

Chris approved these for temporary private-template placeholder use on 2026-08-21. That approval is not public redistribution clearance. Before a public release, obtain written rights confirmation or replace them with assets carrying a compatible license.

## Explicit exclusions

- No Joiner imagery is included or approved.
- `cosmico2025_jjamesjoiner_45.jpg` and any imagery containing minors must remain excluded.
- Do not add event-, venue-, artist-, or year-specific photography to the generic template.

Until rights are cleared, remixers should replace the placeholders through `src/platform/media/placeholderMedia.ts`.
